# Data

## Raw data

Recorded trajectory data are provided by an external research partner and are
not included because they may be subject to data-sharing restrictions.

## Simulated example data

The public examples [example_trajectory_01.csv](simulated/example_trajectory_01.csv)
and [example_trajectory_02.csv](simulated/example_trajectory_02.csv) contain
trajectories generated by the simulator under `tools/ship_simulator`. All motion
and reference states are simulated in local Cartesian coordinates. The simulator
does not require a GPS reference.

The CSV columns are:

- `time`: elapsed simulation time in seconds.
- `x`, `y`: local position in metres.
- `ground_truth_x`, `ground_truth_y`: reference position in metres.
- `ground_truth_velocity`: reference speed in metres per second.
- `ground_truth_yaw`: reference heading in radians.
- `ground_truth_turn_rate`: reference turn rate in radians per second.

The `ground_truth_*` columns are used by the Bayesian Predictor for display and
evaluation only. Inference uses the trajectory observations. The simulator
currently exports `x` and `y` equal to the reference positions.

Generate and save new simulated trajectory data from the project root:

```bash
uv run ship-simulator
```

By default, the simulator exports one sample every two simulated seconds and
suggests filenames such as `simulated_trajectory_01.csv` in `data/simulated/`.

To inspect an included example, start the Bayesian Predictor and select its CSV
file:

```bash
uv run bayesian-predictor
```
